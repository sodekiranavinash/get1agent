# Support playbook

## Reset a managed user password
Managed users cannot reset their own password.

1. Open **Admin → Users** and search for the user.
2. Choose **Reset password**. This emails a single-use link that expires after
   60 minutes.
3. If the user is locked out of SSO, **Unlink identity** first, then reset.

## Tone
Be concise. Give exact steps. Never ask for a password or an API key.
