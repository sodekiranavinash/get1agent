## Getting started

OneAgent (powered by get1agent.com) is a workspace for building, running and evaluating AI agents on your own data.

OneAgent lets you assemble agents and multi-agent workflows from four building blocks: knowledge (retrieval over your documents), tools (web search, code, HTTP, a managed browser and remote MCP servers), skills (reusable instructions) and models. The platform is fully AWS-native — built on 10+ AWS services with every model call on Amazon Bedrock — and per-user, so your data, files and conversations are private to your account.

## Getting started

1. Create a knowledge base on the Knowledge page and upload documents, or write knowledge directly. Ingestion, chunking and indexing happen automatically.
2. Upload any supporting files to Storage if you want to attach them to an agent later.
3. Add provider API keys to the Vault if you want runs billed to your own key, or keep using the platform models.
4. Build an agent in the Agent builder: pick a model, attach knowledge bases, MCP servers and skills.
5. Run the agent from Chat, or chain several agents together in the Workflow builder.
6. Inspect every run on Traces, tune prompts in the Playground, and measure quality in Evaluations.

**The fastest path** — Create one knowledge base, build one agent with just a prompt and that knowledge base, then run it from Chat. Add tools, skills and schedules once the basics work.
